## 🛡️ 2. 영구 아키텍처 규칙: 제로 리소스(Zero-Resource) 원칙

모든 개발 및 유지보수는 저사양 PC에서도 부담 없이 구동될 수 있도록 다음 성능 기준을 절대적으로 준수해야 합니다:

1. **💾 하드디스크 (SSD) I/O 0 Byte**:
   - 게임/기능 구동 중 임시 파일, 캐시, 지속적 로그 파일 작성을 원천 금지합니다.
   - 모든 런타임 게임 상태는 RAM 메모리 내에서만 처리합니다.
2. **🧠 RAM 가비지 컬렉터(GC) 압박 0화**:
   - GDI+ 렌더링 루프(`OnPaint`) 내부에서 `new Font`, `new Brush`, `new Pen`, `new GraphicsPath`의 반복 생성을 금지합니다.
   - 모든 폰트/브러시는 **정적 캐시(Static Cache)** 또는 레이아웃 변경 시 1회성 계산으로 보관하여, 프레임당 GC 할당량을 0으로 유지합니다.
3. **⚡ CPU 스마트 유휴 절전 (Smart Idle Sleep)**:
   - 무조건적인 60 FPS `Invalidate()` 루프를 금지합니다.
   - 애니메이션(플립, 파티클, 쇼크웨이브)이 진행 중이거나 마우스 인터랙션이 발생할 때만 화면을 갱신하고, 평상시에는 렌더링을 쉬어 **유휴 CPU 점유율 0.0%**를 유지합니다.
   - 탭 비활성화 및 창 최소화 시(`VisibleChanged`) 애니메이션 타이머를 즉시 중지하여 **백그라운드 CPU 점유율 0.0%**를 보장합니다.
4. **⚡ 스내피(Snappy) 반응성**:
   - 모든 타일 뒤집힘, 버튼 조작 피드백은 둔탁한 렉 느낌이 없도록 **70~80ms 이내의 경쾌하고 즉각적인 애니메이션**으로 처리합니다.
