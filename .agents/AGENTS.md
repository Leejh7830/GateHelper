## 🛡️ 2. 영구 아키텍처 규칙: 제로 리소스(Zero-Resource) 원칙

모든 개발 및 유지보수는 저사양 PC에서도 부담 없이 구동될 수 있도록 다음 성능 기준을 절대적으로 준수해야 합니다:

1. **💾 하드디스크 (SSD) I/O 0 Byte**:
   - 게임/기능 구동 중 임시 파일, 캐시, 지속적 로그 파일 작성을 원천 금지합니다.
   - 모든 런타임 게임 상태는 RAM 메모리 내에서만 처리합니다.
2. **🧠 RAM 가비지 컬렉터(GC) 압박 0화**:
   - GDI+ 렌더링 루프(`OnPaint`) 내부에서 `new Font`, `new Brush`, `new Pen`, `new GraphicsPath`의 반복 생성을 금지합니다.
   - 모든 폰트/브러시는 **정적 캐시(Static Cache)** 또는 레이아웃 변경 시 1회성 계산으로 보관하여, 프레임당 GC 할당량을 0으로 유지합니다.
3. **⚡ CPU 스마트 유휴 절전 (Smart Idle Sleep)**:
   - 무조건적인 60 FPS `Invalidate()` 루프를 금지합니다.
   - 애니메이션(플립, 파티클, 쇼크웨이브)이 진행 중이거나 마우스 인터랙션이 발생할 때만 화면을 갱신하고, 평상시에는 렌더링을 쉬어 **유휴 CPU 점유율 0.0%**를 유지합니다.
   - 탭 비활성화 및 창 최소화 시(`VisibleChanged`) 애니메이션 타이머를 즉시 중지하여 **백그라운드 CPU 점유율 0.0%**를 보장합니다.
4. **⚡ 스내피(Snappy) 반응성**:
   - 모든 타일 뒤집힘, 버튼 조작 피드백은 둔탁한 렉 느낌이 없도록 **70~80ms 이내의 경쾌하고 즉각적인 애니메이션**으로 처리합니다.

## 📌 4. 최근 작업 내역 (최종 업데이트: 2026-10-26)

### [SandBox 2번 - '시그널 링크(SignalLink)' 전면 대개편 및 고성능 최적화 완료]
1. **고속 마우스 드래그 궤적 보간 (Bresenham Line Interpolation) 탑재**:
   - 기존의 엄격한 맨해튼 거리 1 검사로 인해 마우스를 빠르게 움직이면 선이 끊기던 결함을 전면 해결.
   - 마우스 이동 속도에 상관없이 중간 노드를 연속 보간하여 단 1칸도 놓치지 않고 자석처럼 착 감기는 쫀득하고 스내피한 조작감 확립.
2. **사용자 요청 고난이도 '스텔스 암기 모드(Stealth Memory Mode)' 전격 계승 및 강화**:
   - 10×10 대형 매트릭스(EXPERT)에 사용자가 선호하는 블라인드 암기 기믹을 정식 시스템화.
   - 단말 노드가 평상시에는 암호화된 바이오메트릭 잠금 상태(`?`)로 은폐되고, 호버/드래그/힌트 시에만 진짜 네온 색상이 복호화되어 스릴 넘치는 기억력+논리 회로 연결 플레이 완성.
3. **무제한 Undo (`Z`) 및 스마트 선로 잘라내기 (Path Trimming)**:
   - 사소한 실수로 처음부터 다시 그려야 했던 스트레스 원천 해결.
   - 언제든 `Z` 키나 헤더 버튼으로 1수 되돌리기, 이미 완성된 선로의 중간을 클릭하면 해당 지점까지만 남기고 즉시 잘라내며 이어서 그리기 가능.
4. **2×2 맵 규모 선택 화면 도입 & GDI+ 순수 캔버스화**:
   - 둔탁한 WinForms MaterialButton/Panel 덮어쓰기 구조를 100% 제거하고, 4대 작전 규모(5×5 입문, 6×6 전술, 8×8 코어, 10×10 스텔스) 선택 화면 및 글래스모피즘 HUD 완비.
5. **하드웨어 제로 리소스 아키텍처**:
   - 매 프레임 Font/Pen/Brush 생성 누수를 없애고 100% 정적 캐싱 적용 (GC 압박 0).
   - 유휴 시 렌더링 루프 정지, 탭 비활성화 시 자동 절전(`0.0% CPU`).
6. **무결점 빌드 및 통합 테스트 100% 통과**:
   - MSBuild Release: **0 Warnings, 0 Errors**.
   - 단위/통합 테스트: `test_signallink.exe` (53/53 PASS), `test_bitflip.exe` (50/50 PASS).

### [SandBox 1번 - '비트 플립(BitFlip)' 전면 대개편 및 고성능 최적화 완료]
1. **맵 규모 선택 화면 (Pre-Game Map Selection Screen) 전격 도입**:
   - 게임 진입 시 임의의 퍼즐로 바로 시작되지 않고, **4대 침투 매트릭스 규모(3×3 입문, 4×4 전술, 5×5 방화벽, 6×6 양자 마스터)**를 먼저 선택할 수 있는 2×2 그리드 글래스모피즘 선택 화면 구현.
   - 인게임 상단 헤더의 `[🌐 MAP]` 버튼 또는 `ESC` 키로 언제든 맵 선택 화면으로 안전 복귀.
   - 승리 결과 모달에 `[규모 선택 🌐]` 버튼 추가하여 클리어 후 바로 다른 맵 규모 선택 가능.
   - 맵 선택 중에는 게임 시계 타이머가 정지되어 불필요한 플레이 타임 누적 방지.
2. **초고속 스내피 플립(Snappy Flip) & 응답성 혁신**:
   - 기존 둔탁한 플립 보간(`0.09f`, 12~14프레임 약 350~450ms)을 **`0.25f` (단 4프레임, ~70ms) 초고속 즉각 반응**으로 개선.
   - 클릭 즉시 탄력 있는 스프링 바운스(`PulseScale -0.08f`)와 함께 날렵하고 쫀득한 클릭감 구현.
3. **GF(2) 선형대수학 AI 엔진 & 6대 전략 기믹 확립**:
   - 불쾌한 괴롭힘 기믹(화면 암전, 커서 드리프트, 클릭 렉, 임의 폭파) 전면 퇴출.
   - 100% 풀이 보장 역산 시뮬레이션 퍼즐 생성기 및 GF(2) 가우스 소거법 AI 힌트(`H`), Par 최적수 3성 평가 시스템 구축.
   - 표준, 대각선, 라인 레이저, 절연 방화벽, 양자 얽힘, 키/잠금 노드 완비.
4. **하드웨어 제로 리소스 아키텍처 완성**:
   - **하드디스크(SSD) I/O 0 Byte**: 런타임 디스크 쓰기 완전 차단.
   - **RAM GC 압박 0화**: 17종 폰트/브러시 정적 캐싱으로 렌더링 중 GC 할당 0 byte 달성.
   - **CPU 스마트 절전**: 유휴 시 렌더링 루프 정지, 탭 비활성화 시 타이머 자동 중지(`0.0% CPU`).
5. **빌드 무결성 및 전체 테스트 100% 통과**:
   - MSBuild Release: 0 Warnings, 0 Errors.
   - 단위/통합 테스트: `test_bitflip.exe` (50/50 PASS), `test_mapselect.exe` (18/18 PASS).
6. **AI 힌트 클릭 시 폼 Red X(빨간 엑스) 크래시 원천 해결**:
   - **원인**: 힌트 활성화 시 `_globalPulse`가 증가하는데, `DrawQuantumLinkBeams`에서 `Math.Sin(_globalPulse * 2f)`의 음수 구간에서 알파값이 음수(`-4` 등)로 계산되어 `Color.FromArgb`에서 `ArgumentException` 발생 -> `OnPaint` 크래시로 폼 전체에 빨간 엑스 표출.
   - **해치**: 펄스 공식을 `0.5f + 0.5f * Sin(...)`으로 정규화하고, 모든 GDI+ 투명도 연산에 `Math.Max(0, Math.Min(255, ...))` 클램프 적용.
   - **방어 메커니즘**: `OnPaint` 전체 파이프라인에 최상위 예외 보호 및 클린 배경 폴백을 적용하여 차후 어떤 예기치 못한 GDI+ 글리치에서도 빨간 X가 발생하지 않도록 완전 무결화. 500회 스트레스 테스트 통과.
